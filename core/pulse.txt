Phase 2: Live MT5 Pulse (Market Data Ingestion)

Goal
This module continuously reads live market ticks from MetaTrader 5 (MT5) and stores the latest values in Redis.

Files
- `core/pulse.py`: the running ingestion loop
- `core/pulse.txt`: this documentation

How MT5 integration works (`core/pulse.py`)
1) It connects to your running MT5 terminal using MetaTrader5 credentials loaded from `core.config`.
2) It verifies the connection (it checks that MT5 returns terminal info after initialization).
3) It reads the latest tick for each configured symbol using `mt5.symbol_info_tick(symbol)`.

Configured symbols
- You configure which symbols to read using `MT5_SYMBOLS` in your project root `.env`.
- `MT5_SYMBOLS` must be a comma-separated list, for example:
  `XAUUSD,EURUSD,GBPUSD,USDJPY,BTCUSD`
- `core.config` converts this into a Python list like:
  `["XAUUSD", "EURUSD", ...]`

Redis keys written by Pulse
Pulse writes market values using the exact key pattern:

Market keys
- `market:{symbol}:bid`       -> latest bid (float)
- `market:{symbol}:ask`       -> latest ask (float)
- `market:{symbol}:spread`    -> ask - bid (float, or MT5 spread if provided)
- `market:{symbol}:timestamp`-> tick timestamp from MT5 (Unix time; often milliseconds)

System keys
- `pulse:status`     -> simple status string (starting/running/stopped/error)
- `mt5:connection`   -> connected/failed/disconnected

Multi-symbol architecture (how it scales)
Pulse uses the same logic for every symbol:
1) loop over `symbols`
2) call `get_live_tick(symbol)` (read one tick)
3) call `publish_tick(symbol, tick)` (write the tick to Redis)

Because the module loops over a list of symbols, it supports multiple symbols automatically.

Expected behavior
- Every ~1 second, Pulse tries to refresh ticks for all configured symbols.
- If MT5 reports a symbol is missing or no tick data is available yet:
  - the module logs a warning
  - it skips that symbol for that iteration (it does NOT crash)
- If you stop the script (Ctrl+C):
  - `pulse:status` is set to `stopped`
  - MT5 is shut down cleanly

How to run
1) Ensure your MT5 terminal is running and logged in.
2) Ensure Redis is running (the script writes to Redis).
3) Update your `QUANT_ENGINE_2026/.env` with:
   - `MT5_LOGIN`
   - `MT5_PASSWORD`
   - `MT5_SERVER`
   - `MT5_SYMBOLS` (comma-separated)
4) Run from the project root `QUANT_ENGINE_2026`:
   `python core/pulse.py`

How to check it is working
- In Redis, you should see keys like:
  `market:XAUUSD:bid`, `market:XAUUSD:ask`, etc.
- You should also see:
  - `pulse:status` == `running`
  - `mt5:connection` == `connected`
