============================================================

Create /etc/supervisor/conf.d/quanta.conf:

supervisorctl reread

============================================================
STEP 7: SECURE YOUR VPS
============================================================

# Change root password
passwd root

# Set up SSH key authentication (more secure than password)
# On your PC: ssh-keygen -t ed25519
# Copy public key to VPS: ssh-copy-id quanta@xxx.xxx.xxx.xxx

# Disable password SSH login
nano /etc/ssh/sshd_config
# Set: PasswordAuthentication no
service ssh restart

# Install fail2ban (auto-blocks brute force attempts)
apt install -y fail2ban

# Configure firewall
ufw enable
ufw allow 22    # SSH
ufw allow 8501  # Streamlit dashboard (only if you trust the IP)
# Optionally limit dashboard to your home IP:
ufw allow from YOUR_HOME_IP to any port 8501

============================================================
STEP 8: ACCESS DASHBOARD REMOTELY
============================================================

Option A: SSH tunnel (most secure)
  On your PC: ssh -L 8501:localhost:8501 quanta@VPS_IP
  Then open: http://localhost:8501

Option B: Direct access (add firewall rule for port 8501)
  Open: http://VPS_IP:8501

Option C: Nginx reverse proxy with SSL (most professional)
  (too advanced for initial setup — do this in month 2)
